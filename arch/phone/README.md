# Phone platform work

The primary Anonixex targets are ARMv7-A (32-bit) and AArch64 (64-bit).

There is not yet a supported phone model or a bootable phone image. Before
claiming device support, select one exact phone model and document its SoC,
boot ROM/firmware chain, memory map, device tree availability, display,
touchscreen, storage, and power-management hardware.

Do not flash experimental kernels to a daily-use phone. Initial bring-up
should use an emulator or a spare development board/device with a documented
recovery path.
